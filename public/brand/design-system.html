01belief

A backend is a game.
The score is just hidden.

XP, streaks, worlds, loot — the learning app already had the mechanics. The old identity dressed them as an audit: near-black, one accent, mono labels. Correct, and impossible to be curious in.

belief

Learning is a loop, not a library

You draw a table, you query it, you ship it, you level up. The identity should show the loop — progress you can see from across the room, not a progress bar you have to hover.

enemy

The developer-tool costume

Slate greys, 1px borders, a single electric accent, and a monospace label pretending that seriousness equals rigour. It reads as an audit, and audits are not played twice.

the mark

The table has a face

Wanni is the node you draw first: a header strip, a body, a dog-eared corner. The face is not decoration — it is the product's whole promise that a schema is something you build with, not at.

one sentence, rejectable

Fullstack Wannabe is a browser-only backend playground for self-taught developers that turns schema design into levels you can clear, made of sticker stock, a 2.5px ink edge and six candy worlds.

02material

Sticker stock,
not glass.

Four rules produce every surface in the system. They are cheap to follow and impossible to fake: an edge you can measure, an offset with no blur, one flat fill per object, and a header strip that names what the object is.

Edge

2.5px

Every object is cut from one sheet. The edge is always the foreground colour, so it flips with the theme instead of disappearing.

Offset

4px · 0 blur

Depth is a second sticker underneath, not a light source. A blur would turn paper into plastic.

Fill

1 per object

Flat, saturated, no gradient. The colour is a label, so two colours on one object would be two labels.

Header

names the object
users
id int

Every card, panel and quest carries a strip. It is the same move as the mark, at every scale.

The press

hover → rest → pressed
hover
rest
pressed
disabled

The button does not fade when pressed — it travels into its own shadow, 4px, in 90ms. That single gesture is the difference between a web form and an arcade cabinet.

08decoration

The fun is
a layer, not a font.

Four decorations, each with a job and a limit. They sit behind content, never in it, and they never carry a fact. If a decoration can be mistaken for data, it is deleted.

01 · halftone field — behind a hero, never behind a table
02 · confetti — celebration only, max 8 pieces
03 · quest route — progress maps only

world four

04 · squiggle underline — one per view

allowed

  • — Behind a hero, an empty state, or a completion screen.
  • — Rotated stickers between −3° and +3°, never on text.
  • — As the background of a full-bleed section, at 18% opacity or less.

banned

  • — Behind a data table, an editor, or a chart.
  • — Inside a form field or a focus ring.
  • — Animated on loop while the user is reading code.
09motion

One ease,
three durations.

Things arrive with a small overshoot and leave without one. Nothing loops, nothing floats while you read, and every animation has a finished still.

90ms

press

The button travels into its shadow. Instant feedback, no easing curve needed.

180ms

pop

Menus, chips, theme changes. cubic-bezier(.34,1.56,.64,1) — 12% overshoot, then settle.

420ms

celebrate

XP meter fill and confetti. Runs once per win, never on load.

The meter is eight segments, not a smooth bar. Segments are countable, and countable progress is the entire point of a game.
